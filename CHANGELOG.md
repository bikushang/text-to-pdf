# Changelog

All notable changes to this product are documented in this file.

This project uses a simple versioning format. Dates refer to the product release date.

## [1.0.0] - 2026-10-16

### Initial marketplace release

- Added React-based rich-text document editor.
- Added text formatting tools and supported Tiptap extensions.
- Added document page settings, including available page sizes, orientation, margins, and font options.
- Added page preview and page navigation.
- Added cover-page configuration and cover components.
- Added browser-based PDF generation and download.
- Added JSON document save/load workflow.
- Added automatic content formatting and pagination utilities.
- Added Vite development and production build configuration.
- Added initial marketplace documentation.

### Notes

- Pagination is best-effort and should be validated with the buyer's document content and target browser.
- This release does not include a backend, authentication, cloud storage, or subscription billing.
- The release version and date should be updated if the product is changed before marketplace approval.
